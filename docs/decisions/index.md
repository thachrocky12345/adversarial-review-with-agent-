## About ADRs

ADRs document significant architectural decisions made during the project's development. Each ADR describes:
- The context and problem being addressed
- The decision made
- Alternatives considered
- Consequences (positive and negative)

### Statuses

- **Proposed**: Under discussion, not yet accepted
- **Accepted**: Approved and in effect
- **Deprecated**: No longer relevant or recommended
- **Superseded**: Replaced by a newer ADR

### Creating a New ADR

1. Copy `_template.md` to a new file named `NNNN-title-in-kebab-case.md`
2. Fill in all sections
3. Update this index
4. Submit for review
